Portofolio web modern berbasis **Next.js 16 (App Router)** dan **Tailwind CSS** yang dirancang dengan estetika **Simple Modern Monochrome** dan kepatuhan penuh pada standar **Clean Architecture & Anti-Slop**.

## 📱 3 Proyek Unggulan

1. **IsyaratKu: Real-Time BISINDO Sign Recognition**
   - Sistem pengenalan 32 kosakata Bahasa Isyarat Indonesia (BISINDO) real-time berbasis model ensemble Dual-Stream Deep Residual Bi-LSTM + Temporal Attention (akurasi LOSO Cross-Validation 98.99%, latensi inferensi ~2.3 ms).
   - Frontend mobile client dibangun dengan React Native Expo (TypeScript) dengan streaming frame kamera via WebSocket ke backend FastAPI & PyTorch.
   - Repositori: [GitHub](https://github.com/Vial30/isyaratku_bisindo)

2. **Dipma UNIMUS Mobile: Presensi Perkuliahan QR Code**
   - Aplikasi mobile presensi mahasiswa resmi Universitas Muhammadiyah Semarang (UNIMUS).
   - Mengintegrasikan pemindai barcode QR code berbasis hardware camera berlatensi rendah, sinkronisasi jadwal perkuliahan harian, riwayat kehadiran presisi, dan continuous delivery via Stallion OTA updates.

3. **Smart Room UNIMUS: Reservasi & Manajemen Ruang Kampus**
   - Aplikasi mobile pengelolaan dan peminjaman fasilitas ruang kelas, aula, dan laboratorium di lingkungan Universitas Muhammadiyah Semarang (UNIMUS).
   - Alur verifikasi berjenjang 3 tingkat (Civitas, Admin RT, Pimpinan RT), pencegahan bentrok jadwal realtime, dan integrasi push notification Firebase Cloud Messaging (FCM).
   - Repositori: [GitLab](https://gitlab.com/vial300604/smartroom-mobile-app)
