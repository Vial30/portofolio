# Portofolio Jovian: Fullstack & Mobile Software Engineer

Portofolio web modern berbasis **Next.js 16 (App Router)** dan **Tailwind CSS** yang dirancang dengan prinsip **Clean Tech & Anti-Slop**, serta siap langsung di-deploy ke **Vercel**.

## 📱 Proyek Unggulan

1. **Smart Room UNIMUS: Reservasi & Manajemen Ruang Kampus**
   - Platform mobile (React Native & Expo SDK 57) dengan sistem persetujuan 3 tingkat (Civitas, Admin RT, Pimpinan RT), pencegahan jadwal bentrok, dan integrasi push notification FCM.
   - Repositori: [GitLab](https://gitlab.com/vial300604/smartroom-mobile-app)
2. **Dipma UNIMUS Mobile: Presensi Perkuliahan QR Code**
   - Aplikasi mobile presensi mahasiswa berbasis pemindaian QR code hardware camera berkecepatan tinggi, riwayat kehadiran akurat, dan update Over-The-Air (OTA) via Stallion CLI.
3. **Portal Registrasi & Verifikasi Akademik**
   - Sistem web fullstack berbasis Next.js, Node.js, dan PostgreSQL untuk validasi berkas administrasi kelulusan.

---

## 🛠️ Cara Menjalankan di Lokal

```bash
cd C:\Project\Porto
npm run dev
```
Buka browser di `http://localhost:3000`.

---

## 🌐 Deploy ke Vercel

```bash
git add .
git commit -m "Update portfolio with real mobile projects and anti-slop design"
git branch -M main
git remote add origin https://github.com/USERNAME/portfolio.git
git push -u origin main
```
Lalu impor repositori di [vercel.com/new](https://vercel.com/new) dan klik **Deploy**.
